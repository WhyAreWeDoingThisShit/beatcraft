# Changelog

## v0.1.0 — 2026-04-21

First release.

### Features

- **Project creation wizard** — 3-step flow: title + format, methodology, targets + deadline
- **Beat board** — Drag-and-drop reordering, act groupings, inline title editing, status cycling
- **Methodologies** — Three-Act Structure, Save the Cat, Hero's Journey, Freeform
- **Beat drawer** — Full editing: notes, word count, status, linked characters and places
- **Wiki** — Character and place management with linked-beat lookup
- **Progress page** — Structural bar, word count tracker, activity heatmap, beat breakdown table
- **Project settings** — Edit metadata, targets, methodology; detach to Freeform
- **Export** — JSON, Markdown, and ZIP bundle (JSON + MD + characters.json + places.json)
- **Import** — Restore from JSON export with full ID remapping
- **Global settings** — Theme toggle, import, about, erase-all-data
- **Keyboard shortcuts** — `g b/w/r/s` navigation, `n` new beat, `/` search, `?` help
- **PWA** — Installable, offline-first with service worker precache, update prompt
- **Offline banner** — Shows when `navigator.onLine === false`
- **Sidebar** — Project list, per-project navigation, install prompt, theme toggle
- **Accessibility** — ARIA landmarks, roles, aria-expanded, focus-visible rings throughout
